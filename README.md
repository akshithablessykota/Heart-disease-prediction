# ❤️ Heart Disease Prediction

## 📌 Project Overview
This project predicts whether a patient has heart disease using machine learning classification algorithms.

## 📂 Dataset
The dataset contains patient health information such as age, cholesterol, blood pressure, chest pain type, and other medical attributes.

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 🤖 Machine Learning Models
- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)

## 📊 Model Performance
Random Forest achieved the highest accuracy among the evaluated models.

## 📈 Project Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Feature Engineering
5. Model Training
6. Model Evaluation
7. Performance Comparison

## 📌 Conclusion
This project demonstrates how machine learning techniques can assist in the early prediction of heart disease, helping support timely clinical decisions.
